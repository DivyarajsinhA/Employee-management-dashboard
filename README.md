# Employee Management Dashboard

A responsive **Employee Management Dashboard** built with **React.js, TypeScript, CSS (Tailwind CSS), and REST API integration** to centralize staff profile management, multi-parameter search/filtering, full CRUD workflows, and interactive workforce analytics.

## Key Features
- **Employee Records**: Centralized profile directory with table and card views plus a 360° slide-over employee drawer to view, track, and maintain staff data.
- **Real-Time Search & Multi-Parameter Filtering**: Instant search across name, employee ID, role, email, location, and skills alongside filters for Department, Work Status, Employment Type, Location, and Salary Band (₹ LPA).
- **Full CRUD & REST API Integration**: Add, edit, patch status, and delete single or bulk employee records with form validation, live external REST API sync (`GET /users`), CSV export, and an interactive REST API request console.
- **Dashboard Analytics**: Interactive Recharts visualizations covering Department Headcount & Average CTC, Workforce Status Split, 6-Month Growth & Attendance Trend, and Department Performance Matrix.

## Local Setup & Run
```bash
npm install
npm run dev
```
